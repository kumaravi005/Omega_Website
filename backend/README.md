# Backend

Not implemented yet. This is a placeholder for a future backend service —
for example, to receive submissions once an admission/enquiry form is built
(see the frontend's `EnquiryOptions` component and `/admission` page).

in this folder should be treated as a working service until that changes.

[`../frontend/README.md`](../frontend/README.md) for the website itself.
